# Yggvion · Flutter client

Native client for Android, iOS, macOS, Windows and Linux.

[Project overview](../readme.md) · [Documentation](../docs/README.md) · [Build and sign](../docs/building.md) · [Contribute](../CONTRIBUTING.md)

Run from this directory:

```sh
flutter pub get
flutter run -d macos
```

The app works locally without a VPS. Follow the build guide to package the optional server installer or configure signing for distribution.
