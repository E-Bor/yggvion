For development conventions and pull requests, see [CONTRIBUTING.md](../CONTRIBUTING.md). Report vulnerabilities through the private channel described in [SECURITY.md](../SECURITY.md).

Yggvion is a personal workspace with an optional self-hosted server. It has no browser client, shared multi-user projects or user-registration service. Version 0.1 does not claim complete compatibility with Google Calendar or Obsidian. Platform-specific behavior and security boundaries are documented in the guides above.
